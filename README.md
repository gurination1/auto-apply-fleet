# 🚀 Autonomous Tech Job & Paid Internship Cloud Fleet

Autonomous 24/7 cloud application engine operating on **GitHub Actions (GHA)** with **Cloudflare WARP tunnel / residential proxy integration**, **Playwright stealth DOM automation**, and **live Gmail IMAP receipt verification**.

## 📊 Milestone Target: 2,000 Verified Submissions
- **1,000 Remote Tech Jobs** (Targeting $80k–$180k+ USD Base)
- **1,000 Paid Tech Internships** (Stipends: $3,500 – $8,500 / mo USD)
- **Zero Machine Learning Policy**: Strictly focused on Frontend (React/Next.js), Full-Stack, Web Systems, Voice AI, and Cloud Automation.

## 🛡️ Cloudflare WARP & Proxy Architecture
- Cloud-native GitHub Actions runner automatically provisions `cloudflare-warp`.
- Routes all Playwright browser traffic through local SOCKS5 proxy on `127.0.0.1:40000`.
- Bypasses datacenter IP rate limits, CAPTCHA hurdles, and bot detection grids.

## 📬 Performance Determination Engine
- Direct Gmail IMAP scanner verifies actual delivery of employer confirmation receipts.
- Generates live Markdown summary in GitHub Actions run overview (`GITHUB_STEP_SUMMARY`).
- Auto-syncs SQLite database (`verified_job_applications.db`), proof screenshots (`submission_proofs/`), and interactive dashboard (`live_dashboard.html`).
